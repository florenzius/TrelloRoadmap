# Project workflow

Use English for the UI, documentation, and conversation. The product name is **Trello Roadmap**.

Implement and test each iteration locally, then present it for user validation. The user has authorized pushing iterations after validating them: once the user confirms the iteration is accepted, commit and push the agreed changes without asking for duplicate permission. Do not push an unvalidated iteration.

Never commit `.local/`, Trello credentials, or personal screenshots. Preserve browser preferences and the encrypted local connection when changing or moving the application.
